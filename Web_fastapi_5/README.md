### База данных объявлений Hyunday Solaris на avito.ru + регистрация

Для запуска:

- В консоли перейти в папку Web_fastapi_5>;
- Набрать uvicorn app:app --host localhost --port 8000
- Перейти по ссылке http://localhost:8000;
- Откроется страница с базой автомобилей регистрацией пользователя;
- Внизу есть список зарегистрированных пользователей;
- Осталось с 4 проекта: фильтр по году -  вбиваем год - нажимаем на "применить фильтры" - получаем все авто выбранного года;
- Осталось с 4 проекта: фильтр по пробегу - вбиваем пробег - нажимаем на "применить фильтры" - получаем список авто с пробегом = или > указанного;
- Осталось с 4 проекта: показатели средней, минимальной и максимальной цены меняются в соответствии с новым отфильтрованным списком.
