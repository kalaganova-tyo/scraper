### База данных объявлений Hyunday Solaris на avito.ru

Для запуска:

- В консоли набрать Web_api_4_project> python app.py;
- Перейти на  http://127.0.0.1:5000;
- Откроется страница с базой автомобилей;
- Фильтр по году -  вбиваем год - нажимаем на "применить фильтры" - получаем все авто выбранного года;
- Фильтр по пробегу - вбиваем пробег - нажимаем на "применить фильтры" - получаем список авто с пробегом = или > указанного;
- Показатели средней, минимальной и максимальной цены меняются в соответствии с новым отфильтрованным списком.
